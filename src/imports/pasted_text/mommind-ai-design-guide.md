====================================================
3. GLASSMORPHISM DESIGN SYSTEM
====================================================

Use sophisticated glassmorphism throughout important dashboard components.

Glass cards should have:

• Semi-transparent warm-white background
• Approximately 70–85% opacity
• Backdrop blur approximately 18–28px
• Very subtle 1px white/translucent border
• Soft shadow
• 18–24px corner radius
• Layered depth
• Soft peach/coral background glow

Avoid excessive glass effects.

Information must remain highly readable.

Primary floating components such as:
• AI assistant
• Prediction cards
• Today's schedule
• Quick actions
• Voice interface

can use stronger glass effects.

====================================================
4. PARALLAX & MOTION DESIGN
====================================================

Create the UI with implementation-ready motion specifications.

Use subtle parallax effects.

Examples:

Dashboard background:
Slow-moving soft coral/peach gradient blobs.

When scrolling:
Foreground cards move normally while decorative background elements move approximately 10–20% slower.

Baby profile/avatar:
Very subtle floating/parallax movement.

AI orb:
Gentle breathing animation when idle.

Voice mode:
Reactive waveform/glowing orb.

Prediction cards:
Small depth movement when entering viewport.

Marketplace:
Subtle depth between category icons/cards and background.

Avoid aggressive animation.

Motion should feel:
calm,
premium,
smooth,
comforting.

Suggested durations:
Micro-interactions: 150–250ms
Card transitions: 250–400ms
Page transitions: 300–450ms

Respect:
Reduce Motion accessibility setting.
